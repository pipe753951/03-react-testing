# #09. Índice de cobertura en Vitest

Para obtener el índice de cobertura de Vitest, se utiliza el comando `npx vitest run --coverage` ó el comando de NPM asociado al anterior. Este comando hace todas las pruebas y devuelve un resumen de cobertura en la terminal. Además, crea una carpeta llamada `coverage` en el proyecto que contiene un HTML que muestra información detallada de las pruebas.
